**圈圈叉叉.cpp**

為解決判斷是否連線的問題，我找出了一種不需大量使用判斷式的方法：
* Array代表棋盤且利用PrintArray顯示棋盤於終端機
* Msg_get_pos接收輸入座標並以PlayerEvent判斷玩家所選的座標是否合法
* CheckWin函式中以row代表橫向連線的三種可能、col代表直向連線的三種可能、m代表斜向連線的兩種可能，for迴圈內加總所有的座標數值(1="O",0="X")寫入陣列後判斷其中一項只要等於3則"O"獲勝,如果為0則"X"獲勝
